# Seguridad

Si encuentras un fallo de seguridad en Chubasco (la app de escritorio, la web,
el widget o el intermediario del radar en `proxy/`), **no abras un issue
público**. Avísame en privado desde
[Report a vulnerability](https://github.com/lalesena/chubasco/security/advisories/new)
(pestaña *Security* del repositorio). Solo lo veremos tú y yo hasta que esté
arreglado.

Cuenta qué has visto, cómo reproducirlo y qué versión usas (Ajustes → versión,
o la fecha si es la web). Intentaré responder en una semana.

Solo se mantiene la última versión publicada.

---

*English:* please report security issues privately through
[Report a vulnerability](https://github.com/lalesena/chubasco/security/advisories/new),
not in public issues. Only the latest release is supported.
